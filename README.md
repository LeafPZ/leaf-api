### Requirements

- Java 25 or higher

### Installation

To install the API, you can simply subscribe to it on the Steam workshop.

### Usage

To use the API in your own mod, simply add it as a regular maven dependency:

```kotlin
dependencies {
    api("dev.aoqia.leaf:api:1.0.0")
}
```

### Development

You can build the project like so:

```shell
./gradlew build
```
